# 最佳实践模式库

> 这里是一套**可落地的模式库**：每篇文档把一个框架能力点写成一条落地模式（原则 + 代码骨架 + ⚠️约束 + 反模式），读者照着即可生成正确代码。新模块开发 = 查模式 + 套模板——把示例中的聚合 / 存储替换成目标场景，即得新实现（举一反三）。

## 模式链路

从聚合建模到读模型与事件一致性，本模式库覆盖全链路：

```text
写模型建模 → 应用编排 → 持久化 / 读模型 → 基础设施装配 → 事件与一致性
```

| 环节 | 覆盖的落地问题 |
| --- | --- |
| 写模型建模 | 聚合边界怎么划、表怎么落、实体 / 值对象 / 枚举怎么写、规则码与操作码怎么声明 |
| 应用编排 | 应用服务层怎么与聚合协作、校验规则怎么落地 |
| 持久化 / 读模型 | 写模型仓储怎么实现、聚合到异构存储的读模型怎么落 |
| 基础设施装配 | MySQL / Elasticsearch 客户端怎么装配 |
| 事件与一致性 | 事件怎么建模、跨模块消息怎么可靠投递 |

## 如何使用

1. **找模式**：新模块先定位到对应环节（建模 / 编排 / 持久化 / 装配 / 事件），找到最贴近的落地模式文档。
2. **套模板**：把文档中的示例聚合 / 存储替换为目标场景，按代码骨架逐个落地组件。
3. **避坑**：对照每篇的 ⚠️ 约束与常见反模式表，在实现前预判易错点。
4. **验证**：落地后按各篇的规则自检，并补充单元测试。
