# BP 卡：聚合写设计文档模板（写模型）

> 源：`documentation/best-practices/design-doc-write-template.md` · 派生时间：2026-10-20 · 框架版本：2.0.0

## 1. 定位

聚合写（写模型）设计文档模板，落地 `docs/design/{聚合名}-aggregate-design-v{N}.md`。三份文档之一、**主文档**：横切章节（改动清单 / 测试 / 风险 / 时序）在本份**统管整体需求**（含读侧与持久化侧落地）。

## 2. 12 节骨架

| # | 章节 | 必选 |
| --- | --- | --- |
| 1 | 概述与背景 | ✅ |
| 2 | 聚合边界与职责 | ✅ |
| 3 | 领域模型静态结构 | ✅ |
| 4 | 状态与行为设计 | ✅ |
| 5 | 业务规则设计 | ✅ |
| 6 | 领域事件设计 | 视场景 |
| 7 | 应用层设计 | 视场景 |
| 8 | 接口层设计（写） | 视场景 |
| 9 | 时序（写路径） | ✅ |
| 10 | 改动清单与落地顺序 | ✅（统管整体） |
| 11 | 测试清单 | ✅（统管整体） |
| 12 | 风险与待确认事项 | ✅（统管整体） |

> 规则：第 6/7/8 节按场景选填；其余 9 节恒必选。不适用节保留标题写「本次不适用，原因：……」。

## 3. 要点

- 结论先行（顶部引用块，含版本行与「替代 v(N-1) 章节」）。
- 修改类 §1.3 三层根因（直接 / 深层 / 本质，本质落职责 / 边界）。
- 静态结构给可直接编译骨架（真实包名 / 导入 / 构造）；枚举出入参用 `Integer` / 字符串基础类型。
- 状态类需求含允许矩阵；前置规则标注读旧快照 `old`（框架 `execute` 先领域逻辑后校验）。
- 横切 §10–§12 **覆盖写 + 读 + 持久化整体**，不在读 / 持久化文档重复。
- 代码引用统一 `行号:相对路径`。

## 4. 自检（12 项）

结论先行 / 三层根因 / 边界含「不归本聚合管」/ 可编译骨架 / 允许矩阵 / 「不属于本设计」/ 旧快照 / 应用接口层齐全 / 改动清单含整体路径+动作+说明 / 落地顺序每步可编译 / 测试含确切码值标验收核心 / 风险含触发条件与应对且缺口标「不在本次范围」。
