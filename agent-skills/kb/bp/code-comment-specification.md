# BP 卡：代码注释规范（code-comment-specification）

> 源：`documentation/best-practices/code-comment-specification.md` · 派生时间：2026-10-18 · 框架版本：2.0.0

## 1. 定位与适用范围

注释只承载三类业务语义信息（代码表达不了的部分）：

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| 业务口径 | 单位/币种/取整/编码来源/取值域 | `实付金额：平台优惠后，与 platformDiscount 同币种` |
| 边界约束 | 状态迁移范围、写入时机、只读/不可逆 | `只推进物流状态，不改动支付状态` |
| 副作用事实 | 记录操作、收集事件、触发同步 | `记录 ADD_ITEM 操作，不发布事件` |

**不属注释职责**：实现步骤、伪代码、类型复述、示例代码、需求编号、版本历史。

| 层 | 元素 | 强度 |
| --- | --- | --- |
| 领域模型 | 聚合根/实体字段（命中 §1.3 清单） | 必填业务口径 |
| 领域模型 | 公有业务方法 | 必填：意图+状态迁移范围+副作用 |
| 领域模型 | 公有构造 | 必填：创建语义/初始状态/副作用 |
| 应用服务 | `{Action}Input` 类 | 必填三要素 |
| 应用服务 | Input 字段（命中 §1.3） | 必填调用方口径 |

> 值对象/领域事件/参数对象/接口层 DTO 注释按 `AGENTS.md` 通用要求；本文不强制。

## 2. 什么时候必须写（非自解释才必填）

字段命中以下任一类必写业务口径：

| # | 类别 | 判定信号 | 写清 |
| --- | --- | --- | --- |
| 1 | 金额/数量 | `Money`/`BigDecimal`/数值 | 单位、币种、含税与优惠口径 |
| 2 | 时间 | `LocalDateTime`/`Instant`/时间戳 | 业务本地还是系统时间、谁写入 |
| 3 | 编码/状态 | 含 `code`/`status`/`type` | 业务来源、取值域 |
| 4 | 派生字段 | 计算所得 | 由谁派生、何时刷新 |
| 5 | 外部回填 | 外部返回后写入 | 来源系统、写入时机 |
| 6 | 非直观命名 | 歧义或业务专有词 | 业务含义与易混淆字段区别 |

> 同一类内风格必须一致；可省≠随手补翻译句。判定法：不熟悉业务者无法说出字段业务口径即必写。

## 3. 写法要点

- **字段**：Javadoc 块注释，业务含义 + 命中清单时的口径；禁同义反复（`/** 商品 ID */`）、持久化细节、类型复述。
- **业务方法**：写清①做什么②影响哪些状态（相邻状态易误判时写「不改什么」）③副作用（recordOperation/collectEvent/数据同步）。`@param` 只写业务口径，名已表达时省略。
- **构造**：业务构造写创建语义+初始状态+副作用；无参 `protected` 重建构造写「仅供持久化框架重建」。
- **Input 类**：三要素——业务语义、与协议无关自有扁平结构（不引用领域值对象）、由哪 Factory/Updater 转换。
- **Input 字段**：写调用方必须知道的口径（金额币种/单价小计/已扣优惠；业务时间还是系统时间+时区；编码型字段来源；金额+币种→Money 组合）。

## 4. 形式规范

| 项 | 规则 |
| --- | --- |
| 位置 | 字段/方法上方；禁行尾 `//` 与行尾块注释 |
| 单行/多行 | 单句 `/** ... */`，多句或含边界用多行块；同内一致 |
| 分段 | 多段用 `<p>` |
| 元信息 | 作者按团队约定；不写 `@version`/`@since`/日期/需求号 |
| `@param` | 只写业务口径，禁复述参数名/类型 |
| 术语 | 与标识符、领域术语一致 |
| 语言 | 中文、中文标点、句末句号 |

## 5. 常见反模式

| 反模式 | 正确做法 |
| --- | --- |
| 翻译式注释 | 名自解释则省略，否则写业务口径 |
| 命中金额/时间/编码却不写口径 | 按 §1.3 补 |
| 注释代替命名 | 先改命名再补口径 |
| 过期注释 | 注释与行为不一致视为缺陷，随代码同改 |
| 写实现步骤/伪代码 | 只写意图、边界、副作用 |
| 业务方法漏状态边界 | 写清推进什么、不推进什么 |
| `@param` 复述参数名 | 省略或补业务口径 |
| 注释放示例代码 | 示例放文档，注释只写规则 |
